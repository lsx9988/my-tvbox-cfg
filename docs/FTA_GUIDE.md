# 开源公开频道（FTA）本地播放器合规用法指南

> 本文档说明如何使用**电视台主动在网上免费公开**的信号（FTA, Free-To-Air），在 VLC 及其他本地播放器中观看。
> 仅面向公开、免费、可合法访问的频道；**不含**任何付费台、赛事、付费影视的未授权线路。

---

## 一、合规边界：什么能看，什么不能看

| ✅ 合规可看 | ❌ 不合规，不要导入 |
| --- | --- |
| 电视台主动在官网 / 官方 App 免费开放的信号（公共台、国家新闻台、社区台、广告赞助的 FAST 频道） | 付费体育台、付费影视台、PPV 赛事等未经授权的转播 |
| 社区整理的 FTA 合集（只收录上述公开信号） | 标称"免费"却混入 Sky / beIN / HBO 等付费内容的列表 |
| 判断口诀：**该台在官方渠道本就免费，指向同一信号的 M3U 才正当；原本要订阅付费的，免费 M3U 基本属于盗播** | 公开在网上被转发，并不代表转发行为已获授权 |

> M3U / M3U8 只是一个"地址清单文件"，本身不存储片源；合规与否取决于清单指向的信号是否被授权公开。

## 二、可用的开源公开源（先选列表，再导入播放器）

| 源 | 列表地址 | 特点 |
| --- | --- | --- |
| iptv-org · 全量 | `https://iptv-org.github.io/iptv/index.m3u` | 170+ 国家、上万条 FTA，社区每日更新；全量较大、含少量临时死链 |
| iptv-org · 按国家 | `https://iptv-org.github.io/iptv/countries/cn.m3u`（`cn` 换成 `gb` / `us` / `de` 等两位国家代码） | **推荐优先用国家切片**，地域匹配好、死链少 |
| iptv-org · 按分类 | `https://iptv-org.github.io/iptv/categories/news.m3u`、`.../categories/sports.m3u` | 只要新闻 / 体育等单一类目 |
| Free-TV 精选 | `https://raw.githubusercontent.com/Free-TV/IPTV/master/playlist.m3u8` | 约 500 条、人工核验、HD 优先，适合起步 |

### 选源判断要点
- **看最近提交日期**：仓库天天更新才健康；半年以上未更新的列表基本已过期。
- **死链比例**：健康列表通常有 5%–15% 临时死链属正常；若一半以上打不开，是源本身过期，直接换掉。
- **优先国家 / 分类切片**，不要一上来用上万条全量索引。
- **地域限制**：境外台在境内可能被 geo-lock，属正常；想看国内公开频道，优先用国内社区整理的公开 / IPv6 台清单。

## 三、VLC（桌面 Windows / macOS / Linux）导入

### 方式 A：在线 URL（推荐，列表随源更新）
1. 打开 VLC → 菜单 **媒体（Media）→ 打开网络串流（Open Network Stream）**。
2. 粘贴上面任一 M3U / M3U8 地址 → 点 **播放（Play）**。
3. 打开 **视图（View）→ 播放列表（Playlist）** 浏览频道，双击切换。

### 方式 B：本地 .m3u 文件
1. 浏览器打开列表地址，另存为 `.m3u` / `.m3u8` 文件。
2. VLC → **媒体 → 打开文件**，选中该文件即可。

> VLC 是纯本地播放器，不内置任何片源，只解析你提供的清单地址。

## 五、EPG（节目单）说明

- 列表里的 `tvg-id` 只是频道标识，**节目单是另一套 XMLTV 数据源**，需要在播放器里单独配置 EPG 地址，才会显示"接下来播什么"。
- iptv-org 配套提供 EPG 索引；在播放器的 EPG / 电子节目指南设置里填对应 XMLTV 地址，并确保 `tvg-id` 与之一致。

## 六、常见问题排查

| 现象 | 原因 / 处理 |
| --- | --- |
| 单条打不开 / "无法打开 MRL" | 该信号临时下线或被地域锁定；换别的台，属正常现象 |
| 全部打不开 | 先在浏览器打开 M3U 地址，应看到以 `#EXTM3U` 开头的纯文本；若能打开，再检查本机防火墙 / 杀毒 / VPN 是否拦截播放器联网 |
| 卡顿、画质差 | 多为源端带宽或地域限制；换国家切片 / 精选列表，或换线路 |
| 节目单不显示 | EPG 地址未配置，或 `tvg-id` 与 EPG 不匹配 |
| 列表臃肿、死链多 | 用 M3U 编辑器在本地删死链、重命名分组，导出一份精简清单再导入（本地处理，不上传服务器） |

## 七、使用自查清单

1. 只选 **FTA / 广告赞助 FAST** 类公开源，不导入含付费台、赛事、付费影视的列表。
2. 优先用**国家 / 分类切片**，而不是全量索引。
3. 确认仓库**近期仍在更新**，并保留第二个备用源。
4. 不向第三方"IPTV 会员 / 套餐"付费，不在来路不明的 App 里登录个人账号。
5. 观看到的内容仍受当地版权与播出许可约束；正式追剧、看赛事请走持牌正规平台（有线电视、运营商 IPTV、正版视频 App）。

## 附：与本仓库配置的关系

- 本仓库 `output/` 下的 TVBox 配置与直播清单，面向 FongMi / TVBox 客户端使用；本文档讲的是**通用本地播放器 + 开源公开频道**的合规用法，两者播放器内核不同，清单格式（M3U）互通。
- 本仓库自动抓取的直播台以官方 CDN / 公开清单为准；第三方点播站的版权与稳定性由各自源方负责，使用时请自行甄别。

### 点播（影视）说明

- 开源公开生态**只有直播 FTA 索引，没有合规开源的公开影视片源库**：不存在可直接接入 TVBox、由社区免费公开授权的电影 / 电视剧片源或采集 API。
- 现有配置里的点播站均为第三方聚合采集接口（Apple CMS 类），片源版权与稳定性由各自源方负责；LibreTV、EcoHub 等开源项目只是**自托管聚合壳**，自身不存片，仍需自行填入第三方采集接口。
- 正规追剧、看电影请走持牌正版平台（有线电视、运营商 IPTV、正版视频 App）。
